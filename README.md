Image Steganography in C

Overview

Image Steganography is a C-based project that hides secret text data inside a BMP image using the **Least Significant Bit (LSB) technique**.

The project allows users to encode a secret text file into a BMP image and retrieve the hidden information through decoding. It modifies the least significant bits of image pixel data to embed the secret message while maintaining the visual appearance of the original image.

Features

- Encode secret text files into BMP images.
- Decode and retrieve hidden text data from encoded images.
- Uses the Least Significant Bit (LSB) technique.
- Checks image capacity before encoding.
- Validates the hidden data using a magic string.
- Supports command-line arguments for encoding and decoding.

Technologies Used

- Programming Language: C
- Concepts: Pointers, Structures, Bit Manipulation, File Handling
- Technique: Least Significant Bit (LSB)
- Image Format: BMP
- Compiler: GCC

How It Works

Encoding

1. Read the source BMP image.
2. Open the secret text file.
3. Check whether the image has sufficient capacity to store the secret data.
4. Embed the secret data into the image using the LSB technique.
5. Generate the encoded BMP image.

### Decoding

1. Open the encoded BMP image.
2. Extract the hidden data from the image's least significant bits.
3. Verify the magic string.
4. Retrieve the secret message and store it in a text file.

Compilation

Compile the source files using GCC:

bash
gcc *.c 


Execution

Encode

bash
./stego -e beautiful.bmp secret.txt

Decode

bash
./stego -d encoded.bmp

Note: Use the actual encoded image filename generated by your program.
